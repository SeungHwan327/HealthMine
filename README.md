🏋️ HealthMine

HealthMine은 사용자의 운동 기록을 쉽고 직관적으로 관리하고, 운동 데이터를 기반으로 볼륨을 분석할 수 있는 iOS 운동 기록 애플리케이션입니다.

매일 진행한 운동을 날짜별로 기록하고, 푸쉬(Push) · 풀(Pull) · 레그(Leg) 분할 운동을 관리할 수 있습니다. 각 운동의 무게와 반복 횟수를 입력하면 운동 볼륨을 계산하여 분할별 평균 볼륨과 최고 기록(PR)을 확인할 수 있습니다.

HealthMine은 복잡한 운동 관리 서비스보다 개인이 자신의 운동 기록을 빠르고 간편하게 작성하고, 축적된 데이터를 통해 운동량을 확인할 수 있도록 만드는 것을 목표로 합니다.

운동 기록을 단순히 저장하는 것에 그치지 않고, 운동 볼륨과 분할별 데이터를 분석하여 자신의 운동 패턴과 성과를 쉽게 확인할 수 있도록 구현하고 있습니다.
